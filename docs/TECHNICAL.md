# 기술 설명

## 데이터 묶음 (MDB1 `.mvgl`)

`CR3/resources/*.psp2.mvgl`은 Media.Vision의 MDB1 아카이브입니다. 이름 표, 파일 항목 표, 데이터 표로 되어 있습니다. 데이터는 개별 압축된 블록입니다.
- 읽기: `tools/mvgl.py`
- 재구성: `tools/repack.py`
  - 바꾼 항목만 새로 압축해 넣습니다.
  - 나머지 항목은 원본 블록을 그대로 복사합니다.
  - 오프셋 표를 다시 씁니다.

## 문자열

| 종류 | 위치 | 처리 |
| --- | --- | --- |
| 대화 메시지 `.dat` | `CRDB` `message/`, `CRDBboot` | `tools/msg.py`: (키, 문자열) 쌍 목록을 파싱·재작성. `\d123` 화자 코드, `\n` 등 제어 코드는 보존 |
| 데이터 표 `.mbe` | `CRDB` `data/` | `tools/mbe.py`: 시트·열 정의를 읽고 문자열 칸만 교체(길이 제한 없음) |
| BSON 데이터 | `CRDB` `data/*.bson` | `tools/bsonpatch.py`: 문자열 참조 레코드(u16 0x14, u16 0x0c, u32 key, u32 val)의 val을 파일 끝에 덧붙인 새 문자열의 오프셋으로 교체 |
| 스크립트 `.nut` | `CRDB` `script/` | 원문 목록에는 들어 있지만(4개) 현재 빌드에서는 교체하지 않음 |

모든 원문은 `tools/extract_all.py`가 중복 없이 한 목록으로 모읍니다(24,378개). 번역은 그 목록의 번호로 연결됩니다.

## 글꼴

게임은 `font/TBGB_0KP.TTC`(TrueType 컬렉션, 두 글꼴)를 런타임에 그립니다.
- 병합 도구: `tools/fontbuild.py`(fontTools)
- 대상: 두 글꼴 모두
- 넣는 글자: 번역에 쓰인 한글 2,354자
- 원본 글꼴: 나눔스퀘어네오 Bd
- 원본 글꼴의 em 크기와 기준선에 맞춰 크기를 조정했습니다.

## 그림 글자 (GXT)

UI 그림은 PS Vita GXT 텍스처입니다. 형식은 UBC3/DXT5 스위즐이고 밉맵이 있습니다. `tools/gxt.py`가 디코드·인코드하며, 인코드할 때 밉맵 전체를 다시 만듭니다.

`tools/imgpatch.py`는 정의(`text/images/spec_*.json`)대로 다음 순서로 작업합니다.
1. 지정한 상자의 원래 글자를 지웁니다. 지우는 방식은 세 가지입니다.
   - `row`: 좌우 가장자리 색으로 보간
   - `clear`: 투명하게 지움
   - `none`: 지우지 않음
2. 한국어를 그립니다(채움색·외곽선·정렬 지정).

작은 메뉴 라벨은 밉맵이 축소될 때 뭉개지기 쉽습니다. 그래서 갈무리 대신 굵은 고딕을 썼습니다.

타이틀 화면은 로고 그림 아래에 한글 부제를 덧그렸습니다. `CRDBcardhd`의 카드 뷰어 닫기 버튼은 HTML 안의 문자열을 바꿨습니다.

## 검증

- `tools/check_tr.py`: 번역마다 다음을 원문과 비교합니다.
  - 제어 코드·변수(`{name}`, `%d` 등)의 개수
  - 줄 수
- `tools/emu.py`: Vita3K를 백그라운드로 띄우고 키 입력·터치·스크린샷으로 화면을 확인합니다.
